# Практика по PyTorch

## Цель

Получить навыки практической работы с PyTorch.

---

## Описание / Пошаговая инструкция выполнения домашнего задания

Используя **PyTorch**, необходимо:

1. Создать и обучить **регрессионную модель**, которая аппроксимирует значение функции:

   $$
   f(x, y) = \sin(x + 2y) \cdot \exp\left(-(2x + y)^2\right)
   $$

   на диапазоне значений $x, y \in [-10; 10]$.

2. В качестве обучающей выборки сгенерировать **20 000 точек** случайным образом.

3. Разделить получившийся датасет на:
   - **train** — 70%,
   - **test** — 15%,
   - **val** — 15%.

---

## Результаты

Необходимо предоставить:

- **a)** Значение метрики **Mean Square Error (MSE)** на тестовой выборке.

- **b)** График, на котором сравниваются:
  - истинная функция,
  - её аппроксимированный вариант (предсказания модели).
